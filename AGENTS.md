# Istruzioni per CODE SPACE – Python Edition

- Videogioco educativo per l’orientamento Ferraris di sabato 28 novembre 2026. Pubblico di terza media alle prime armi, oltre 15 PC contemporanei, lezione di 35–40 minuti.
- Sito statico per GitHub Pages, budget zero, nessuna installazione per gli studenti, registrazione, raccolta di dati personali, API esterna o backend. Tutte le dipendenze runtime sono locali e tutti i percorsi sono relativi.
- Interfaccia italiana, HTML5, CSS3, JavaScript modulare, Canvas 2D per il gioco, Skulpt in modalità Python 3 in un Worker dedicato, LocalStorage per i progressi.
- Supportare Chrome, Edge e Firefox. Mirare a 60 FPS con adattamento ai PC meno potenti. Privilegiare stabilità e correttezza didattica.
- In missione eseguire realmente il codice e valutare valori e tipi. Accettare soluzioni equivalenti. Vietato confrontare il sorgente con una risposta modello o usare eval/Function nel codice applicativo sugli input. Il Worker è isolamento operativo, con limiti e terminazione, e non costituisce da solo una barriera di sicurezza.
- Visione, missioni e direzione visiva in [SPECIFICATIONS.md](SPECIFICATIONS.md). Conservare README.md e LICENSE, fissare versioni e conservare licenze e attribuzioni delle dipendenze. Evitare framework e dipendenze superflui.
- Lavorare solo sulle fasi autorizzate. Sono autorizzate 00 e 01. Fase 02, motore grafico e pubblicazione richiedono autorizzazione.
- Eseguire i test JavaScript e browser pertinenti, distinguere risultati effettivi e controlli ancora da fare, correggere le regressioni e ripetere i test. Tenere separati i commit delle fasi se consentito.
