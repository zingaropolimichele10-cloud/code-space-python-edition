# Risoluzione dei problemi

| Sintomo | Intervento |
| --- | --- |
| Pagina bianca o file non caricati | Apri l’URL HTTP(S) corretto, con la barra alla fine del sottopercorso Pages. Per lo ZIP esegui il server dalla cartella con index.html e conserva tutte le sottocartelle. |
| La navicella non si muove | Chiudi il Centro o la finestra delle impostazioni. Torna nella scheda del gioco e premi **Riprendi**. Le frecce nell’editor spostano il cursore. |
| Errore di sintassi o di rientro | Segui la riga indicata. Controlla i due punti dopo if e il rientro di quattro spazi. Le stringhe usano virgolette semplici o doppie diritte. |
| Python non risponde o segnala troppe risorse | Riduci ciclo, valori o output; poi riprova. Puoi uscire dalla missione e riprenderla. Se il browser arresta la scheda, ricarica e usa **Continua**. |
| Grafica poco fluida | Attiva **Grafica leggera**, chiudi schede pesanti e riprova. Il docente può ridurre difficoltà o disattivare gli asteroidi. |
| Continua assente dopo il ricaricamento | Mantieni la stessa origine, porta e profilo. Controlla le regole su LocalStorage. Il gioco resta giocabile con progressi in memoria se il salvataggio è bloccato. |
| Offline non disponibile | Ripeti il primo caricamento online fino all’attivazione e riprova sullo stesso profilo. Usa lo ZIP con il server locale se il browser blocca la cache. Su LAN HTTP assicurati che il server condiviso sia raggiungibile. |
| Il browser mostra un aggiornamento | Chiudi tutte le schede CODE SPACE e riapri l’URL. Cancella i dati del sito solo come ultima risorsa, perché perderesti i progressi. |
| Audio assente o indesiderato | Usa il pulsante audio e regola il volume dalle impostazioni. Mantieni il mute durante la lezione se non sono previste cuffie. |
| Una postazione non vede il server LAN | Controlla l’IP, la porta, la rete e il firewall con il referente IT. Passa a una copia ZIP su loopback se necessario. |
